* Package install
The dependency installation procedure depends on the [[https://docs.conda.io/en/latest/][conda package mananger]]. One ideal way to install conda is to use the reduced [[https://github.com/conda-forge/miniforge][miniforge]] installer. To speed up installation, it is recommended to install mamba alongside conda (since "vanilla" conda is written in Python and can be extremely slow). To install mamba use:
```
conda install conda-forge::mamba
```
With mamba installed, create a conda environment for the dependencies and install [[https://www.ros.org][ROS]] through [[https://github.com/RoboStack/ros-noetic][RoboStack]] with:
```
mamba create -n ros_env
mamba activate ros_env

# this adds the conda-forge channel to the new created environment configuration
conda config --env --add channels conda-forge
# and the robostack channel
conda config --env --add channels robostack-staging
# remove the defaults channel just in case, this might return an error if it is not in the list which is ok
conda config --env --remove channels defaults
```
And then install ROS1 with
```
mamba install ros-noetic-desktop
```
Then deactivate and reactivate the environment with
```
mamba deactivate
mamba activate ros_env
```

For describing robot poses and kinematics calculations we use [[https://github.com/petercorke/robotics-toolbox-python][Robotics Toolbox Python]]. With the ROS environment active, install it with:
```
mamba install conda-forge::roboticstoolbox-python
```

*** Scripting motions
Predefined motions of the robot (e.g. picking brushes/pens, dipping) are defined as simple Python scripts that can be dinamically loaded by a ~TibaInterface~ object. A script can accept a number of "arguments". A simple example of a script contained in a Python file could be:
#+begin_example
require_args("offset_x_mm", "offset_y_mm")
offset = np.array([offset_x, offset_y, 0.0])/1000 # Movement in meters
move_xyz(offset)
#+end_example
The scripts moves the end effector along the "x" and "y" directions (forward/back, sidewise) by the given amounts `offset_x_mm` and `offset_y_mm` specified in millimeters and without changing the orientation of the end effector.
The ~require_args~ function at the beginning makes sure that an error is thrown early on if the required arguments are not provided.  From code, the path for the robot can be computed using the ~plan_script~ method in ~TibaInterface~, e.g. if we have an interface object ~itiba~ and a script in the "move_xy.py" file, we can plan the motion with ~itiba.plan_script('move_xy.py', offset_x_mm=10, offset_y_mm=2)~. The arguments passed to the functions will be injected into the script and made avaialbe.

def SE3_interp(a, b, t):
    pa = a.t
    pb = b.t
    qa = UnitQuaternion(a)
    qb = UnitQuaternion(b)
    rots = R.from_quat([np.array(qa), np.array(qb)])
    slerp = Slerp([0, 1], rots)
    d = pb - pa
    if type(t) is float:
        res = np.concatenate([pa + t*d, slerp(t).as_quat()])
        print(SE3.isvalid(np.array(tu.to_pose(res))))
        return res
    res = [np.concatenate([pa + ti*d, slerp(ti).as_quat()]) for ti in t]
    return res
